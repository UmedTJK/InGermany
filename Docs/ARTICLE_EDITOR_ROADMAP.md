📄 Article Editor / Mini-CMS Roadmap - ПОЛНОСТЬЮ АКТУАЛИЗИРОВАНО 24.10.2025

## 🎯 Цель
Создать **визуальный редактор статей** как отдельное **macOS приложение InGermanyCMS**, которое:
- ✍️ создает статьи для основного iOS приложения InGermany  
- 👀 показывает Live Preview в реальном времени
- 📤 экспортирует JSON в совместимом формате с iOS приложением
- 📥 импортирует JSON обратно для редактирования
- 📚 управляет библиотекой статей через файловую систему

## 🏗️ АРХИТЕКТУРА (ПОЛНОСТЬЮ РЕАЛИЗОВАНО)

### 📦 Мультиплатформенная архитектура с общим ядром
```
📁 InGermany/                          # Основной iOS проект
├── InGermany.xcodeproj               # iOS приложение для чтения
├── Sources/                          # iOS-specific UI и логика
└── Package.swift                     # Зависимость от ArticleKit

📁 InGermanyCMS/                      # Отдельное macOS приложение
├── InGermanyCMS.xcodeproj           # macOS приложение для редактирования  
├── Sources/                          # macOS-specific UI
└── Package.swift                     # Зависимость от ArticleKit

📁 Packages/ArticleKit/               # ОБЩЕЕ ЯДРО - Swift Package
├── Sources/ArticleKit/
│   ├── Models/                       # Общие модели данных ✅
│   │   ├── ArticleBlock.swift        # Модель блока редактора
│   │   ├── ArticleModels.swift       # DTO модели для рендеринга
│   │   └── BlockType.swift           # (интегрирован в ArticleBlock)
│   ├── ViewModels/                   # Общая бизнес-логика ✅
│   │   ├── ArticleEditorViewModel.swift # Логика редактора
│   │   └── ArticleLibraryViewModel.swift # Логика библиотеки
│   └── Renderer/                     # Кросс-платформенный рендерер ✅
│       └── ArticleRenderer.swift     # Рендерер статей
└── Package.swift                     # Конфигурация пакета ✅

📁 UIUtils/                           # Вспомогательные утилиты
└── NSWindow+SwiftUI.swift            # Расширение для окон macOS ✅
```

### 🔄 Поток данных между приложениями
```
InGermanyCMS (macOS Editor)           InGermany (iOS Reader)
         ↓                                     ↑
   Создание/редактирование              Потребление контента
         ↓                                     ↑
   ArticleKit (Общее ядро)            ArticleKit (Общее ядро)  
         ↓                                     ↑
   JSON Export → File System →        JSON Import ← Resources/
```

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ РЕАЛИЗАЦИИ

### 📁 Формат хранения статей

public struct ArticleDocument: Codable, Identifiable, Hashable {
    public var id: UUID
    public var title: String
    public var sections: [ArticleSectionDTO]
    public var url: URL?
}
```

### 🔄 Преобразование моделей

// ArticleBlock (редактор) ↔ ArticleSectionDTO (рендерер)
ArticleBlock.fromSection(_:)    // DTO → Editor model
ArticleBlock.toSectionDTO()     // Editor model → DTO
```

### 🎨 Поддерживаемые типы блоков

public enum BlockType: String, CaseIterable {
    case paragraph, info, warning, tip, quote
    case checklist, faq, list, links, image
}
```

### 🖼️ Модель данных изображений
```swift
public struct ImageData: Codable, Equatable {
    public var imagePath: String?  // Путь к файлу в файловой системе
    public var caption: String     // Подпись к изображению
    public var altText: String     // Альтернативный текст для доступности
}
```
