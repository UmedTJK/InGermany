# 📄 Article Editor / Mini-CMS Roadmap

## 🎯 Цель
Создать полноценный **визуальный редактор статей** для  приложения InGermany, который со временем превратится в **мини-CMS** (content management system) и отдельное **Admin-приложение для MacOS**.  

Редактор должен позволять:
- ✍️ создавать новые статьи (title + структурированные блоки),  
- 👀 видеть Live Preview,  
- 📤 экспортировать JSON в совместимом формате,  
- 📥 импортировать JSON обратно в редактор,  
- 📚 управлять библиотекой статей.  


### 🔹 Базовый редактор
- [x] **Создание статьи с блоками** (paragraph, info, warning, tip, quote, list, checklist, faq, links, image)
- [x] **Редактирование блоков** (TextEditor, список, чеклист, FAQ, ссылки, изображения)
- [x] **Удаление блоков** с подтверждением
- [x] **Drag & Drop сортировка** блоков (полная поддержка `.onMove`)
- [x] **Live Preview** через ArticleRenderer в реальном времени

### 🔹 Управление данными
- [x] **Экспорт JSON** (поддержка `ArticleDocument` с `title` и `blocks`)
- [x] **Импорт JSON** через `ArticleEditorViewModel.importFromJSON()`
- [x] **Автосохранение** в `Documents/article.json`
- [x] **Share JSON** через системное меню iOS
- [x] **Unit-тесты** на экспорт/импорт (симметрия проверена)

### 🔹 Библиотека статей
- [x] **ArticleLibraryView** с полным управлением статьями
- [x] **Просмотр метаданных** (название, дата изменения)
- [x] **Открытие статей** в редакторе через навигацию
- [x] **Удаление статей** с файловой системы
- [x] **Автообновление** библиотеки при изменениях

### 🔹 Поддержка изображений

- [x] **DemoArticleView** для тестирования эталонных статей

### 🔹 UX/UI улучшения

## 📊 АРХИТЕКТУРА СИСТЕМЫ

### 🗂 Ключевые файлы

#### Модели данных
- **`Shared/Editor/Models/ArticleBlock.swift`** - основные модели блоков (`BlockType`, `BlockPayload`, `ArticleBlock`)
- **`Shared/Editor/Models/ArticleSectionDTO.swift`** - DTO для совместимости с ArticleRenderer

#### ViewModels
- **`Shared/Editor/ViewModels/ArticleEditorViewModel.swift`** - логика редактора: управление блоками, экспорт/импорт JSON, преобразование в DTO
- **`Shared/Editor/ViewModels/ArticleLibraryViewModel.swift`** - управление библиотекой статей, метаданные, файловые операции

#### Views
- **`Shared/Editor/Views/ArticleEditorView.swift`** - главный редактор с live preview и панелью инструментов
- **`Shared/Editor/Views/ArticleLibraryView.swift`** - библиотека статей с навигацией
- **`Shared/Editor/Views/BlockPickerView.swift`** - выбор типа блока

#### Компоненты рендеринга
- **`Shared/Editor/Views/ArticleComponents/ArticleBlockView.swift`** - универсальные блоки (info, warning, tip, quote)
- **`Shared/Editor/Views/ArticleComponents/FAQBlockView.swift`** - аккордеон вопрос-ответ
- **`Shared/Editor/Views/ArticleComponents/ChecklistCardView.swift`** - интерактивные чеклисты

#### Сервисы
- **`Services/ArticleRenderer.swift`** - рендерер статей (совместим с редактором)

#### Интеграция
- **`Views/SettingsView.swift`** - точка входа в редактор через Debug секцию
- **`Views/DemoArticleView.swift`** - демонстрация эталонного рендеринга

### 🔄 Поток работы

```
1. SettingsView (Debug Section) 
   → ArticleLibraryView (выбор статьи)
   → ArticleEditorView (редактирование)
   
2. ArticleEditorView:
   - Редактирование заголовка и блоков
   - Live Preview через ArticleRenderer
   - Экспорт в Documents/article.json
   - Импорт из существующих JSON
   
3. ArticleLibraryView:
   - Просмотр всех статей в Documents/
   - Сортировка по дате изменения
   - Удаление статей
```

### 📤 Формат экспорта JSON

```json
{
  "title": "Название статьи",
  "blocks": [
    {
      "type": "paragraph",
      "content": "Текст параграфа"
    },
    {
      "type": "image",
      "url": "https://example.com/image.jpg",
      "caption": "Подпись к изображению",
      "base64": "data:image/jpeg;base64,..."
    },
    {
      "type": "checklist",
      "items": [
        {"text": "Пункт чеклиста", "isDone": false}
      ]
    }
  ]
}

## 🔹 Этап 1. Подготовка проекта

1. Создать новый **Workspace** в Xcode, объединяющий iOS-приложение и новый macOS-таргет.

   ```
   InGermany.xcworkspace
   ├─ InGermany (iOS)
   ├─ InGermanyCMS (macOS)
   └─ Packages/
       └─ ArticleKit (SPM)
   ```
2. Вынести общие файлы (модели, редактор, рендерер) в Swift Package `ArticleKit`.

   * `ArticleBlock.swift`, `ArticleSectionDTO.swift`
   * `ArticleEditorViewModel`, `ArticleLibraryViewModel`
   * `ArticleRenderer` + ArticleComponents
   * сервисы (FileRepo, JSONCodec)

👉 Цель: чтобы iOS и macOS использовали один и тот же код.

---

## 🔹 Этап 2. Базовое macOS-приложение

1. Создать таргет `InGermanyCMSApp` (macOS, SwiftUI App).
2. Добавить `NavigationSplitView` с двумя колонками:

   * Sidebar = список статей (`ArticleLibraryView`).
   * Detail = редактор статьи (`ArticleEditorView` + Live Preview).
3. Подключить DI через `CMSContainer` (репозиторий статей, хранилище изображений, publisher).
4. Настроить файловое хранилище:

   ```
   ~/Documents/InGermany/Articles
   ~/Documents/InGermany/Media
   ```
